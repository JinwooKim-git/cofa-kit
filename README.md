# cofa-kit

AI 코딩 에이전트(Codex)와 일할 때 쓰는 개인 작업 규칙, 문서 템플릿, 스킬입니다.
특정 과제의 답, 데이터, 코드는 들어 있지 않습니다. 반도체 현장 내용은 판단을 돕는 어휘·질문·확인 방법이고 정답이 아닙니다.

## 사용법
```bash
git clone https://github.com/JinwooKim-git/cofa-kit /tmp/cofa-kit   # 작업 폴더 밖에 받기
bash /tmp/cofa-kit/setup.sh                                         # 과제 작업 폴더에서 실행 (기존 파일은 덮어쓰지 않음)
```
지시문 모음은 setup 뒤 `docs/PROMPTS.md`에 생깁니다.

## 구성
- `AGENTS.md` — Codex 작업 규칙 (단계 진행, 핵심 결정·지킬 항목, 최적화 과제 원칙, 실패 처리, 8D 축약 AI 협업 기록, 서버 포트, 커밋)
- `PLAN.md` — 지금 상태·목표·성공 기준·지킬 항목·모형·핵심 결정·실패 모드·단계·변경 이력
- `LOG.md` — 담당자 합의, 가정, 환경 확인, AI 협업 기록
- `VERIFY.md` — 독립 재계산, 최적화 결과 점검, 남은 한계
- `NOTES.md` — 내가 만든 것을 내 말로 정리 (설명·발표 대비)
- `PROMPTS.md` — 시간대별 지시문 (담당자 있음/없음 두 버전)
- `skill-*.md` — Codex 스킬 8개 (setup.sh가 `.agents/skills/이름/SKILL.md`로 복사)

## 스킬
| 스킬 | 언제 | 하는 일 |
|---|---|---|
| `$kickoff` | 시작 직후 | README·데이터·요구 문서 파악, 과제 유형, 쓸 수 있는 라이브러리, 담당자 질문 또는 가정 목록 (코드 금지) |
| `$opt` | 배치·배정·일정·경로 계산이 있을 때 | 모형 세 줄, 문제 이름, 방법 수준 단계표(사용자가 고름), 설정값, 품질 지표·갭, 독립 검사 계획 |
| `$fab` | 반도체 현장 데이터·운영 과제일 때 | 과제 유형 구분, 현장 어휘, 담당자 질문, 데이터 함정, 방법 카드, 결과 표현 원칙 |
| `$fixlog` | 오류·틀린 결과·검토 지적·방향 변경 | 원인 확인 후 그것만 고치고 전후 비교, 8D 축약 6칸 기록, 커밋 |
| `$check` | 3번 탭 검토 담당 | 최근 작업을 지킬 항목 표와 대조해 문제 최대 3개, 근거 포함 (파일 안 고침) |
| `$verify` | 결과가 나온 뒤 | 결과물 코드와 독립된 재계산, 최적화 결과 점검, 깨질 곳 3개 (고치지 않음) |
| `$freeze` | 마감 전 | 기능 추가 중단, 결과 정리 문서와 3분 설명, NOTES, 커밋 |
| `$mockq` | 제출 전, 3번 탭 | 설명 질문 모의 연습, `$mockq 피칭`은 발표 연습 (파일 안 고침) |
